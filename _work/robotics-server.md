## Overview

A server layer that connects simulated robots with control and planning
components, so experiments can be swapped and re-run without rewiring the
system.

## Focus areas

- **Modularity:** clear interfaces between simulation, control and planning.
- **Reliability:** predictable message handling under load.
- **Integration:** easy to plug new behaviours into the simulation loop.
